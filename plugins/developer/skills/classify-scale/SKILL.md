# Classify Scale

Определение масштаба: разведочная / ограниченная / архитектурная.

## Scales

- **exploratory** — spike; time-box; no production contract change
- **bounded** — clear slice; plan + implement
- **architectural** — decision impact; route via `request-architecture-deviation` / Architect

## Acceptance

Scale recorded; architectural work not silently treated as bounded.
