# Caveman

Упрощённый режим для мелких изменений.

## When

Scale=bounded and change is tiny (few files, no decision impact).

## Steps

1. State intended change in one sentence.
2. Implement + minimal test/verify.
3. Skip multi-phase plan unless complexity grows — then escalate to full plan.

## Acceptance

Still respects stack rules and context slice.
