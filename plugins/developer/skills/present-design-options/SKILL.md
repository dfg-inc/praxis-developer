# Present Design Options

Варианты дизайна реализации с превью для UI-задач.

## Steps

1. Offer ≥2 options within context-slice constraints.
2. Tradeoffs: complexity, risk, reuse of patterns.
3. UI: textual/wire preview acceptable; no silent choice.

## Acceptance

Human picks option before `create-plan` (unless caveman scale).
