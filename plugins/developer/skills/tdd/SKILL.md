# TDD

Red → green → refactor for the current phase.

## Steps

1. Write failing test expressing acceptance.
2. Implement minimum to pass.
3. Refactor; keep tests green.
4. Record evidence in status journal.

## Acceptance

Tests exist before production change for the scoped behavior.
